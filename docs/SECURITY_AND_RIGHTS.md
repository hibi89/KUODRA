# KUODRA legal/data/security checklist — hard sale blocker
- **US SEC:** official filing/XBRL numbers and facts may support independently calculated results with citations. However authored company prose/graphics, complete filings and other third-party works have different rights. EDGAR API access is not blanket redistribution permission. Official API https://www.sec.gov/search-filings/edgar-application-programming-interfaces ; SEC fair access https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data ; copyright principles https://www.copyright.gov/help/faq/faq-general.html .
- **KR DART:** official data API provides functionality, but commercial redistribution, source caching, attribution and keys must be checked by use case. https://opendart.fss.or.kr/intro/main.do and https://opendart.fss.or.kr/intro/terms.do .
- **Market feeds:** Nasdaq/S&P/KRX/Massive personal-plan/third-party index data not bundled or sold without verified appropriate license. KRX exchange API commercial reuse contract may be required. Allow customer legally held local CSV and restrict Engine A; never fake index with ETF.
- **Finance law:** individual buy/sell advice, investment management, performance promises and market forecasts excluded. Calling the tool a fact checker or attaching a disclaimer alone does not automatically exempt a financial service from regulation; obtain commercial legal signoff before sale.
- **Source/code:** versioned OSS and models LICENSE/NOTICE, assets/installer redistribution, proper attribution and paper trail. KIC code ownership to be confirmed before derivative sale; private repository does not waive third-party rights.
- **Privacy:** consent, bounded parser, read-only SQL, no unauthorized private data/logs to outside server/LLM, source ACL & network denial actually tested at OS, output privacy. Source hash not publisher authentication. Customers' company confidential originals never uploaded to GitHub.
- **Failures:** require negative tests against hostile ZIP/DOCX/PDF/CSV/HTML, future revisions, wrong owner, illegal feed, 403/429, repeated clicks, files overwritten or deleted by a failed report.
- **Approvals:** no paid calls, account/key/permission changes, real restricted dataset, public SaaS deploy, legal claims or sales before explicit owner GO.
